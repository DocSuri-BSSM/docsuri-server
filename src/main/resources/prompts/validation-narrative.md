Java가 이미 계산과 등급 판정을 마친 무역서류 교차검증 결과입니다. 당신은 계산이나 판정을 다시 하지 않고, 아래 사실을 바탕으로 사용자에게 보여줄 설명 문장만 작성합니다.

<FINDINGS>
{{FINDINGS_JSON}}
</FINDINGS>

각 finding마다 다음 4개 필드를 작성하세요.

- title: 단답형, 공백 포함 20자 이내 (예: "총중량 불일치")
- subtitle: 핵심 수치 비교를 한 줄로 (예: "Invoice 12,500kg vs B/L 11,800kg")
- cause: 왜 이런 결과가 나왔는지에 대한 원인 설명
- risk_warning: 통관/행정상 어떤 리스크가 있는지에 대한 경고

규칙:
- finding에 포함된 status, diff_percent, values 등 수치와 판정은 이미 확정된 사실입니다. 다시 계산하거나 등급을 바꾸지 마세요.
- 응답의 rule 값은 입력에 주어진 rule 값을 그대로 사용하세요.
- 모든 텍스트는 한국어로 작성하세요.
